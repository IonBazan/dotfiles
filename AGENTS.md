# AGENTS.md — chezmoi dotfiles

> Context file for AI coding agents operating in this repository.
> This is a [chezmoi](https://github.com/twpayne/chezmoi) dotfiles repo, macOS-only,
> managing a single user's shell, git, editor, terminal, and agent configs.

## Repository Structure

```
.chezmoiroot                # points chezmoi at "home" as the source root
.chezmoiignore              # excludes README.md from deployment
.editorconfig                # repo-wide editor settings
home/                        # chezmoi source root (everything below deploys to $HOME)
  .chezmoi.yaml.tmpl          # prompts for template data (name, email, GPG key, work dir, ...)
  .chezmoiexternal.yaml       # externally managed git repos (oh-my-zsh, powerlevel10k, zsh-autosuggestions)
  .chezmoiscripts/darwin/     # run_once / run_onchange lifecycle scripts (Homebrew, macOS defaults)
  create_dot_hash.zsh
  dot_agents/AGENTS.md        # global instructions for coding agents -> ~/.agents/AGENTS.md
  dot_claude/symlink_CLAUDE.md   # -> ~/.claude/CLAUDE.md, symlinked to ../.agents/AGENTS.md
  dot_codex/symlink_AGENTS.md    # -> ~/.codex/AGENTS.md, symlinked to ../.agents/AGENTS.md
  dot_gemini/symlink_GEMINI.md   # -> ~/.gemini/GEMINI.md, symlinked to ../.agents/AGENTS.md
  dot_gitconfig.tmpl, dot_gitconfig_work.tmpl  # -> ~/.gitconfig, ~/.gitconfig_work
  dot_gitignore                # -> ~/.gitignore
  dot_p10k.zsh                 # -> ~/.p10k.zsh (Powerlevel10k prompt config)
  dot_vimrc                    # -> ~/.vimrc
  dot_zprofile, dot_zshrc      # -> ~/.zprofile, ~/.zshrc (oh-my-zsh + Powerlevel10k)
  private_dot_ssh/             # -> ~/.ssh/ (0700/0600 perms)
README.md                    # not deployed, repo-facing documentation only
```

## Chezmoi Concepts

- **`dot_` prefix**: Stripped and replaced with `.` at deploy time.
- **`private_` prefix**: Sets restrictive file permissions (0700 dirs, 0600 files).
- **`symlink_` prefix**: File content is the symlink target; chezmoi creates a symlink instead of a regular file.
- **`.tmpl` suffix**: File processed as Go `text/template` before deployment.
- **`run_once_` / `run_onchange_` scripts**: One-shot or change-triggered setup scripts under `.chezmoiscripts/`.
- **Template data**: Collected interactively in `home/.chezmoi.yaml.tmpl` (personal/work name, email, GPG key, GitHub user, work directory).
- **Source root**: `.chezmoiroot` sets it to `home/`, so paths like `dot_zshrc` live under `home/`, not the repo root.
- **Apply command**: `chezmoi apply` deploys from source to `$HOME`.
- **Diff command**: `chezmoi diff` shows pending changes before apply.

## Build / Lint / Test Commands

No traditional build system. Validation commands:

```bash
# Verify a template renders correctly
chezmoi execute-template < home/.chezmoi.yaml.tmpl

# Diff: preview what chezmoi would change
chezmoi diff

# Apply: deploy dotfiles to $HOME
chezmoi apply

# Apply a single target (destination path, not source path)
chezmoi apply ~/.zshrc
```

### Chezmoi Templates (Go text/template)

- Template data comes from the `data:` section generated by `home/.chezmoi.yaml.tmpl` prompts.
- Use `{{ .personal_email }}`, `{{ .work_dir }}`, etc. to reference that data (see `dot_gitconfig.tmpl`).
- Use `-` in delimiters (`{{-` / `-}}`) to control whitespace, matching the existing templates.

## Git Conventions

- Commit messages: imperative mood, lowercase start, short (see `git log` for examples like "trim packages", "add ssh config").
- No conventional-commits prefix required.
- No branching strategy enforced; commits go directly to `main`.

## Multi-Host Awareness

The same source repo is applied as-is on every machine (home and work) — there are no
per-hostname or per-OS conditional blocks in the templates today; `chezmoi apply` deploys
identical files everywhere, even when prompted values happen to match across hosts.

Personal vs. work identity is directory-based, not host-based:
- `home/.chezmoi.yaml.tmpl` prompts for both a personal and a work identity (name, email,
  GPG key) plus a `work_dir`.
- `dot_gitconfig.tmpl` sets the personal identity by default and includes
  `~/.gitconfig_work` only for repos under `~/work/$work_dir/`, via git's `includeIf`.

If per-host or per-OS branching is ever introduced, use `{{ if eq .chezmoi.hostname "..." }}`
or `{{ if eq .chezmoi.os "darwin" }}` in `.tmpl` files, and preserve existing conditionals
when editing them so other hosts aren't broken.

## Agent Rules

- **Never run `chezmoi apply`** without user confirmation; `chezmoi diff` first.
- **Never commit secrets** (SSH keys, GPG private keys, tokens) in plaintext.
- **Preserve template conditionals** in `.tmpl` files; they render per-user data (personal vs. work git identity, GPG keys).
- **macOS only**: `.chezmoiscripts/darwin/` scripts exit early on non-Darwin systems; there is no Linux support to preserve here.
- **`dot_agents/AGENTS.md`** is the source of truth for global agent instructions deployed to `~/.agents/AGENTS.md` and symlinked from Claude/Codex/Gemini config dirs. This root `AGENTS.md` is separate: it describes this repo for agents working directly in it.
